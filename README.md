# V9 — ربط دوام الأطباء والنشر

أضيف في هذه النسخة:
- ملف `schedule_seed.sql` لدوام الأطباء الأسبوعي حسب جداول المركز التي تم إدخالها سابقًا.
- واجهة API للأوقات المتاحة.
- منع حجز المواعيد الماضية.
- لوحة «حجوزات اليوم» للاستقبال.
- API لإدارة دوام الأطباء من لوحة الإدارة.
- API للإعلانات والإحصائيات العامة.
- تجهيز بيانات الأطباء والخدمات وإحصائيات 2025.

مهم: أوقات الدوام في seed مضبوطة افتراضيًا 08:30–15:00 لأن هذا هو وقت عمل المركز العام. إذا كانت بعض العيادات لها فترات مختلفة، عدّل `schedule_seed.sql` قبل التشغيل.

للنشر الفعلي:
1. PostgreSQL.
2. `database.sql`
3. `seed.sql`
4. `schedule_seed.sql`
5. إنشاء مستخدم إدارة بكلمة مرور bcrypt.
6. وضع `DATABASE_URL` و`SESSION_SECRET` في `.env`.
7. HTTPS ونسخ احتياطي دوري.
