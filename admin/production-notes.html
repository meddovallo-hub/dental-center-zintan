ملاحظات تشغيل البوابة الإلكترونية

هذه الصفحة تحتوي على التعليمات الأساسية لتشغيل وإدارة بوابة مركز طب وجراحة الفم والأسنان بالزنتان.

تم تجهيز ملفات الواجهة العامة ولوحة الإدارة وربطها بالهيكل البرمجي للمشروع.

1. قاعدة البيانات

يستخدم المشروع قاعدة بيانات PostgreSQL في بيئة التشغيل الفعلية.

  • إنشاء قاعدة البيانات من ملف database.sql.
  • إدخال البيانات الأولية من ملف seed.sql.
  • إدخال جداول دوام الأطباء من ملف schedule_seed.sql.

2. إعداد ملف البيئة

يتم إنشاء ملف باسم:

.env

ويحتوي على إعدادات الاتصال بقاعدة البيانات والمفتاح السري للجلسات.

لا تقم بنشر ملف .env أو كلمات المرور داخل GitHub.

3. تشغيل الخادم

بعد تثبيت Node.js والحزم المطلوبة، يتم تشغيل الخادم بواسطة:

npm install

ثم:

npm start

4. لوحة الإدارة

لوحة الإدارة موجودة داخل مجلد:

admin/

وتحتوي على:

  • index.html — واجهة لوحة الإدارة.
  • admin.css — تنسيق لوحة الإدارة.
  • admin.js — وظائف لوحة الإدارة.
  • production-notes.html — ملاحظات التشغيل.

5. وظائف لوحة الإدارة

  • إدارة حجوزات المرضى.
  • عرض الأطباء.
  • إدارة الخدمات.
  • إدارة الإعلانات.
  • إدارة الإحصائيات.
  • تسجيل الدخول والخروج للمستخدمين المخولين.

6. النسخ الاحتياطي

يتم استخدام ملف:

backup.sh

لإنشاء نسخة احتياطية من قاعدة بيانات PostgreSQL.

7. الأمان

  • استخدام HTTPS في بيئة الإنتاج.
  • عدم استخدام كلمات مرور افتراضية.
  • تغيير كلمة مرور مدير النظام قبل التشغيل الفعلي.
  • عدم نشر بيانات الاتصال بقاعدة البيانات.
  • تفعيل النسخ الاحتياطي بصورة دورية.

8. معلومات المركز

المركز: مركز طب وجراحة الفم والأسنان بالزنتان

العنوان: الزنتان – المجمع الإداري – خلف مصرف الدم

أيام العمل: الأحد إلى الخميس

ساعات العمل: 8:30 صباحاً – 3:00 مساءً

9. تنبيه مهم

هذه الملفات تمثل مكونات المشروع البرمجية. قبل نشر النظام للعامة يجب إعداد الخادم وقاعدة البيانات ومتغيرات البيئة وHTTPS واختبار جميع وظائف لوحة الإدارة.
